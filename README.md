# PixelFlow

基于二维码的文件/文本传输工具

## 简介

PixelFlow 是一个基于浏览器的轻量级数据传输工具，通过二维码将文件或文本从一台设备传输到另一台设备。无需安装任何应用程序，只需在浏览器中打开即可使用。

## 功能特性

- **双模式传输**：支持文件传输和文本传输两种模式
- **二维码分块**：将数据分割为多个二维码进行传输，解决大数据传输问题
- **实时进度显示**：显示传输进度和块状态
- **跨平台兼容**：基于 Web 技术，支持各种现代浏览器
- **无需服务器**：纯客户端操作，数据不经过任何服务器

## 使用方法

### 发送端 (sender.html)

1. 在电脑或移动设备上打开 `sender.html`
2. 选择传输模式：
   - **文件模式**：点击选择文件或拖拽文件到指定区域
   - **文本模式**：直接在文本框中输入内容
3. 系统会自动将数据分割为多个二维码块
4. 使用接收设备扫描二维码即可开始传输

### 接收端 (index.html)

1. 在另一台设备上打开 `index.html`
2. 使用摄像头扫描发送端显示的二维码
3. 系统会自动接收并重组所有数据块
4. 接收完成后，可查看或下载传输的内容

## 技术原理

- 使用 QR 码作为数据传输载体
- 将大文件或长文本分割为多个数据块（chunks）
- 每个数据块独立编码为二维码
- 接收端通过扫描收集所有数据块并重组为原始数据

## 注意事项

- 确保扫描设备有足够的光线以获得清晰的二维码图像
- 大文件会导致较多的二维码块，传输时间可能较长
- 建议在稳定的网络环境下使用
